## Core Rules for Agents
1. **Visual Fidelity**: Align UI components with the design language established in `sample_UI_img/` (clean card containers, responsive layouts, subtle shadows, and cohesive color palette).
2. **Robust Code Quality**: Write clean, modular, and maintainable code with thorough input validation and graceful error handling.
3. **Verification**: Always verify changes by running tests or validating in the browser before completing tasks.
